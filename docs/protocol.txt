Shared types for JSON messages between the client and agent.

Requests include a shared token. Each message ends with a newline.
Messages are carried over mutual TLS, which encrypts the token and commands.

## StatusResponse

The agent's status, sent as JSON on one line.

## StatusResponse::workload_name

The managed workload's name, or `None` when there is no workload.

## StatusResponse::desired

The requested number of running copies.

## StatusResponse::running

The number of copies observed running.

## StatusResponse::metrics

Optional host CPU and RAM readings. Replies without this field still work.

## HostMetrics

cpu_percent is whole-host CPU usage, or None while warming up.
used_mem and total_mem are bytes, not per-app memory.

## Request

A client command carried inside an authenticated request.

## Request::Status

Ask for the current workload and counts.

## Request::StatusApp

Ask for one app by workload_name. The agent supports this request;
CLI app selection is not wired yet. Unknown names return an error.

## Request::Stop

Set the target to zero and stop all copies.

## Request::StopApp

Stop only the named app.

## Request::ScaleApp

Set the named app's copy count without changing other apps.

## Request::ListApps

Ask for every managed app's status. Requires the same authentication as commands.

## Request::Scale

Change the target; the agent adjusts processes on its next loop.

## Request::LogsApp

Ask for lines from workload_name with IDs greater than after_id.
Use 0 for the oldest stored lines. Requires the same TLS and token checks as controls.

## Response

An agent reply: current status or a reason the request was rejected.

## Response::Status

The workload and current counts.

## Response::Error

A readable error message.

## Response::Apps

The list returned by ListApps, with one StatusResponse per app.

## Response::Logs

A bounded batch of log entries, with IDs, process IDs, stream labels, and text.
Use the last ID as after_id for the next request. Empty entries mean no new lines.
Replies fit the 16 KiB message limit. A line that cannot fit on its own is shortened
with `[truncated]` in the reply; the stored line stays unchanged.
The buffer may drop old entries. IDs reset when the runner is recreated.

## AuthenticatedRequest

A command and the shared token needed to run it.

Debug printing is not derived to avoid accidentally logging the token.

## AuthenticatedRequest::token

The secret read from `FLEET_TOKEN`. Do not log it.

## AuthenticatedRequest::request

The command to handle after checking the token.
