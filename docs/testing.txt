# Test Helpers

## src/deploy/tests.rs

Checks package limits, hashes, short reads, cleanup, and overwrite protection.
Uses temporary folders and sparse files for large size boundaries; no network upload.

## src/agent/tests.rs

### TestWorkload

Makes sure tests reap every child, even if an assertion fails.

### upload tests

Checks the ready, raw bytes, and save-or-error exchange over local mutual TLS.
Also checks that agent upload requests remain disabled and require the token.

## src/client/tests.rs and src/protocol.rs

Checks upload JSON and rejects upload replies in normal client commands.

## src/device_tls/tests.rs

### MissingClientKey

Offers raw-key support but sends no identity when the server requests one.

### transfer

Exchanges actual TLS records in memory, without sockets or saved credentials.

## tests/device_connection.rs

### Agent

Always stop the temporary agent, including when an assertion fails.

### device_dashboard_and_watch_use_the_right_key_for_each_agent

Drives the real terminal UI. Opt-in because it requires the expect executable.
