# Test Helpers

## src/agent/tests.rs

### TestWorkload

Makes sure tests reap every child, even if an assertion fails.

## src/device_tls/tests.rs

### MissingClientKey

Offers raw-key support but sends no identity when the server requests one.

### transfer

Exchanges actual TLS records in memory, without sockets or saved credentials.

### Agent

### device_dashboard_and_watch_use_the_right_key_for_each_agent
