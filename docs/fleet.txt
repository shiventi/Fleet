Fleet is a Rust tool for running and checking apps across your computers.

**Work in progress.** Agents can run several apps, with up to 32 copies each.
Remote commands and views currently require a single-app agent.
Failover and moving files are not ready yet.

## Start Here

Run the local demo:

```sh
cargo run -- run examples/demo.json
```

Fleet starts the requested copies and restarts them when they exit.
Ctrl+C stops the app process groups.

For setup, device approval, and remote commands, see the
[README](https://github.com/shiventi/Fleet#readme).
Use `cargo run -- --help` to see the commands.

## How It Works

1. A JSON file describes the app and how many copies to run.
2. The agent checks the processes and starts or stops copies to match that count.
3. A client sends status, stop, and scale commands over mutual TLS.
4. Watch and dashboard views show replies from the agents in a cluster file.

A running process is not a full health check. An unreachable agent does not
prove its apps have stopped.

## Code Guide

Pick a module to read its notes and browse its types and functions.

| Area | Modules | What to look for |
| --- | --- | --- |
| Commands and files | [CLI](crate::cli), [workload](crate::workload) | Flags, app settings, and validation |
| Running apps | [agent](crate::agent), [runner](crate::runner) | Process checks, restarts, stop, and scale |
| Remote control | [client](crate::client), [protocol](crate::protocol) | Requests, replies, and shared message types |
| Multiple computers | [controller](crate::controller), [dashboard](crate::dashboard) | Cluster files, polling, and the terminal view |
| Host usage | [metrics](crate::metrics) | CPU and RAM sampling |
| Device access | [identity](crate::identity), [trust](crate::trust) | Saved keys and approved peers |
| Secure connections | [device TLS](crate::device_tls), [certificate TLS](crate::tls) | Key checks, encryption, and connection limits |

The main file ties these parts together:

- [`ObservedWorkload`](crate::ObservedWorkload) holds the last process count.
- [`Action`](crate::Action) asks for one copy to start or stop.
- [`plan`](crate::plan) compares the requested count with the observed count.
- [`supervise`](crate::supervise) runs the local check loop.
- [`load_manifest`](crate::load_manifest) and [`load_cluster`](crate::load_cluster)
  read and check JSON files.
- [`load_agent_manifest`](crate::load_agent_manifest) reads single-app or multi-app
  files for both agent modes.

## Access Rules

Remote control needs an approved TLS identity and the shared `FLEET_TOKEN`.
Device-key mode pins the chosen server's public key. Restart agents and clients
after changing approved keys; existing connections are not revoked.

Apps do not inherit the control token, but they are not sandboxed.
Use separate OS users or containers for untrusted apps.
