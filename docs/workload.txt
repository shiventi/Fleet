App settings read from JSON files and the checks they must pass.
Agents accept one app or a list of apps and manage each app's processes separately.

## MAX_REPLICAS

The largest copy count allowed in a manifest or scale request.

## WorkloadSpec

Describes the program and how many copies should run.

## WorkloadSpec::name

The workload's name.

## WorkloadSpec::replicas

The desired number of running copies.

## WorkloadSpec::program

The executable to launch.

## WorkloadSpec::args

Separate arguments passed to the executable.

## WorkloadSpec::validate

Checks the name, executable, and copy count.

Zero replicas and empty argument lists are allowed.
This does not check whether the executable exists or can run.

### Errors
Returns a message if the name or executable is blank, or the count is too high.

## AgentManifest

A nonempty list of apps with unique names, used by both agent modes.

## AgentManifest::workloads

Apps to manage independently, in manifest order.

## AgentManifest::validate

Checks every app and rejects empty lists and duplicate names.
Names are compared exactly; zero copies are allowed for an app.

### Errors
Returns a message for an empty list, an invalid app, or a repeated name.
